# Synthetic Human Core Starter & Bishop Prototype

## Описание

**Synthetic Human Core Starter** — это модульный стартер для реализации логики искусственных людей (андроидов) Weyland-Yutani. Он реализует:
- Приём и исполнение команд с приоритетами (CRITICAL/COMMON)
- Очередь команд с контролем переполнения
- Аудит всех действий (Kafka/консоль)
- Метрики занятости и статистику по авторам
- Единый обработчик ошибок

**Bishop Prototype** — эмулятор, использующий стартер и предоставляющий REST API для демонстрации всех возможностей.

## Архитектура и логика
В основном вся логика была взята из тз, но немного доработал для удобства некоторые моменты.
### 1. Команды
- **CRITICAL** — исполняются сразу
- **COMMON** — попадают в очередь (ограничена по размеру)
- Валидация: описание (до 1000 символов), автор (до 100), время (ISO-8601)
- При переполнении очереди — ошибка
- Поля статуса сообщения **PENDING, EXECUTING, COMPLETED,FAILED**

### 2. Очередь команд
- Реализована на базе `BlockingQueue`
- Обрабатывается отдельным потоком, как и предполагалось в тз
- Время исполнения команды — 1 секунда (симулируем работу)
- Метрика `queueSize` показывает текущий размер очереди

### 3. Аудит
- Все методы, помеченные `@WeylandWatchingYou`, логируются
- Режимы:
  - **Kafka** (по умолчанию, топик `weyland-audit`)
  - **CONSOLE** (вывод в консоль)
- Для Kafka используется Spring Kafka и Jackson (с поддержкой LocalDateTime)

### 4. Метрики
- `/api/metrics/current` — возвращает:
  - `queueSize` — размер очереди
  - `completedCommands` — сколько команд выполнено
  - `authorStats` — сколько команд выполнил каждый автор
  - `methodCallStats` — сколько раз вызывался каждый метод (в том числе через REST)
(далее идут пункты которые я сделал чисто для себя, чисто потестировать и поиграться
поэтому инсутркций по запуску не найдете, сами знаете :)
- Метрики также доступны для Prometheus: `/actuator/prometheus`
- Для визуализации есть Grafna

### 5. Обработка ошибок
- Все ошибки возвращаются в едином формате с кодом, сообщением и timestamp
- Используется глобальный обработчик ошибок
- Было написано совсем немного тестов в стартере, просто потренироваться

## Инструкция по запуску (Docker Compose)

В корне проекта:
```bash
docker compose up -d --build -d
```

- Приложение будет доступно на [http://localhost:8080](http://localhost:8080)
- Prometheus: [http://localhost:9090](http://localhost:9090)
- Kafka: порт 9092 (для аудита)
- многие параметры можно отстроить прямо в докере, например размер очереди

## Структура проекта
- `synthetic-human-core-starter/` — стартер (ядро логики)
- `bishop-prototype/` — эмулятор синтетика (REST API)
- `docker-compose.yml` — запуск всей инфраструктуры
- `prometheus.yml` — конфиг для Prometheus
- `bishop-prototype.postman_collection.json` - PostmanCollection для тестов
